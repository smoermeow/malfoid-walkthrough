# Malfoid production walkthrough

Scripts, exact prompts, reference images, generation videos and production decisions behind two retro-anime episodes by **smoermeow / MORDERKAI**.

**[Open the walkthrough](https://smoermeow.github.io/malfoid-walkthrough/)**

The site includes the finished episodes, character and environment design, scripting, image/video prompting, continuation inputs, revisions and music. Its complete original prompts and native reference media are linked at the relevant steps.

## Reusable skills

The methods are maintained separately in [Creative Skills](https://github.com/smoermeow/creative-skills), including [ChatGPT Project instructions](https://github.com/smoermeow/creative-skills/tree/main/chatgpt-projects). This walkthrough links to that library without duplicating its skill files.

## Browse locally

Open `docs/index.html`, or serve the `docs/` folder with a static web server. GitHub Pages publishes the same folder from `main`.
