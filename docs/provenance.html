Generation walkthrough

Sources, scope and attribution

What this walkthrough includes

Episodes 1 and 2, the finished creator-supplied exports, the in-scope generation parts and alternatives, shared design history, source scripts, exact prompt texts, native reference inputs and direct links to the maintained skills library.

The episode 1 rapid-cut render branch is excluded from the site, prompt archive, media and downloads. Its video-derived extraction galleries are excluded too. Shared still-image designs remain where they independently belong to the episode process.

Source and version distinctions

  • A story script is not the same object as an authoring prompt or submitted provider payload.
  • The linked skills are maintained in the separate Creative Skills repository. Current skill files are not automatically the exact historical execution versions. The examples here retain the recorded prompts and native inputs for each render.
  • The Narrative link leads to its complete maintained instructions and knowledge file. Historical prompt records retain their original version labels.
  • Continuation V3 is the creator-selected public replacement. The older historical tails/frames are not relabelled as V3 outputs.
  • The storyboard skill is the creator’s normal alternative method, not the author of these example scripts.
  • Native image/video files are copied without crop, resize, padding or regeneration.

Audio and editing

The prompts request dialogue/SFX and no music. The creator uses the generated audio with the clips. Extra sound effects were minimal. CapCut is the editor. Episode 1 adds Walked Away from Eleven Music; Episode 2 uses the generated dialogue/SFX without added music. A detailed editing tutorial and screenshots are outside this walkthrough’s scope.

Honest limits

No recorded seeds; historical moodboard contents unavailable; older native Codex CLI image-model version unreported; newer hood-down sheet requested medium but reported low. Exact submitted-revision ties for the first two Episode 1 clips are not established by a receipt. Additional supplied source versions remain labelled without invented prompt associations. Final-export files are identified, but no unverified frame-by-frame edit mapping is asserted.
