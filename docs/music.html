Walked Away / Episode 1 soundtrack

One separate music-generation step, with the actual accidental input preserved.

Walked Away is the creator’s Eleven Music soundtrack for Episode 1. Listen on the official ElevenLabs sharing page. Episode 2 has no added music.

The accidental prompt

The creator accidentally used the lyrics from the first version of the song as the music prompt, supplied the resulting song’s lyrics separately, and kept this render. The displayed inputs below preserve that real setup.

Source: the public song page, with the input roles confirmed by the creator. These are displayed page texts, not an invented reconstruction of the backend request.
