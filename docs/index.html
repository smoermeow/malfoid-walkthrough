The process, in its actual order

  1. Develop the story through iteration

    I supplied the premise, characters and working shot format, then developed the scripts through a normal ChatGPT conversation.

  2. Create the characters and environments

    Original character designs remain visible alongside the sheets derived from them, with exact image prompts and input roles.

  3. Attach the references and divide the script

    Reference mapping, production sections and continuity checks bridge the script and generation.

  4. Write prompts from the actual briefs

    See how each episode started, what V4 was asked to preserve, and how Narrative was introduced later for specific passages. Exact prompts, clips and ordered inputs remain linked.

  5. Continue across generated clips

    Reference-video tails and selected native source frames carry visible state into the next generation.

  6. Assemble the result

    CapCut joins the clips and their generated audio. Episode 1 adds the Eleven Music track Walked Away on ElevenLabs (music prompt and lyrics); Episode 2 has no added music.
