# Make your own

## Keep the workflow; replace the project

Start with your own story, cast and environment. The creator’s two script-development articles show ordinary ChatGPT iteration. If you prefer a dedicated method, the full storyboard skill is provided as an alternative.

### 1. Establish designs before motion

Create an original character design, then make its sheet from that actual image. Give each additional reference a role: identity, clothing, environment, drawing style or composition. Do not allow a style-only image to replace the character identity.

### 2. Divide for production

Break the script into manageable sections. Re-establish each section’s characters, costume, visible state, geography and required dialogue. A new generation does not inherit context from the previous chat prompt automatically.

### 3. Choose the prompt method deliberately

Use Seedance Prompter V4 for its bracketed setup and shot fields. Use the orchestrator-routed Narrative Prompter when that chronological narrative method is wanted. The project’s scoped combinations are explained on the Prompting page; the individual skill READMEs document each standalone method.

### 4. Write the audible action too

The creator’s prompts specify dialogue, voice/performance, ambience and SFX, with no music. Generation produces both picture and audio. For your own project, state the intended audio explicitly and check what the provider actually returns.

### 5. Carry continuity through actual inputs

Use a preceding reference-video tail and a selected native original-source frame where appropriate. Read the V3 continuation skill’s dependencies, source restrictions and range behavior. Keep source media unchanged; do not crop or retime it to hide a mismatch.

### 6. Iterate with a stable baseline

Preserve earlier versions and exact submissions. When changing a prompt, keep the intended scope explicit. Label unrendered drafts and failures accurately. A higher filename revision does not establish approval or a better result.

### 7. Use the generated clips

Assemble the chosen clips with their generated dialogue and sound effects. Extra music is a separate choice. These example videos were assembled in CapCut; the generation walkthrough does not depend on a full editor tutorial.

## A reusable handoff checklist

- Story/script revision and intended section/shot range.
- Complete prompt method plus required knowledge.
- Character/environment references with exact roles and upload order.
- Duration, model and resolution as requested.
- Continuation source, exact source range and selected source frame when used.
- Exact submitted text saved separately from editable authoring notes.
- Returned native media and technical metadata, including discrepancies.
- Review/selection status separate from technical success.

No example on this page authorizes uploads, generation credits or changes to someone else’s working project.
